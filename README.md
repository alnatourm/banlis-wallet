# BANLIS - Loyalty Wallet ☕

بطاقة ولاء رقمية لعملاء بانليس: 5 أختام = قهوة مجانية.

## المزايا الحالية

- صفحة تسجيل العميل: `/join.html`
- إنشاء رابط إضافة بطاقة إلى Google Wallet
- صفحة كاشير: `/cashier.html`
- حماية إضافة الأختام بمفتاح كاشير محفوظ في متغير بيئة
- التحقق من المدخلات وعدم وضع مفاتيح Google داخل ملفات المشروع

## التشغيل

```bash
npm install
npm start
```

## متغيرات البيئة المطلوبة

- `ISSUER_ID`: رقم Google Wallet Issuer ID الحقيقي
- `GOOGLE_CLIENT_EMAIL`: بريد حساب الخدمة المصرح له في Google Wallet
- `GOOGLE_PRIVATE_KEY`: المفتاح الخاص لحساب الخدمة، مع استبدال أسطره الجديدة بـ `\n` عند إدخاله كمتغير بيئة
- `CASHIER_API_KEY`: قيمة طويلة وعشوائية لاستخدام الكاشير

لا ترفع ملف حساب الخدمة أو أي مفاتيح سرية إلى GitHub.

## إعداد Google Wallet

يجب تفعيل Google Wallet API، وإكمال إعداد حساب Google Wallet Issuer، وإنشاء فئة البطاقة `banlis_loyalty` قبل اختبار روابط الحفظ. يجب أن يكون حساب الخدمة مخولاً لإدارة البطاقات.

## حدود هذه النسخة

هذه نسخة أولية وليست نظام ولاء إنتاجياً بعد. لا توجد قاعدة بيانات حتى الآن، لذلك لا يتم حفظ العملاء أو رصيد الأختام على الخادم، كما أن رابط التحديث لا يثبت أن العميل موجود في سجل دائم. يلزم إضافة قاعدة بيانات، وتسجيل دخول للكاشير، وآلية موثوقة لتحديث كائن البطاقة عبر Google Wallet API قبل الاستخدام التجاري.

## الأمان

- لا تضع `.env` أو مفاتيح Google أو كلمات المرور في المستودع.
- اضبط المتغيرات السرية من إعدادات الاستضافة.
- استخدم HTTPS دائماً.
